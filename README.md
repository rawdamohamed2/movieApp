## 📖 About

**CineHub** is a responsive movie and TV browsing application with full user authentication. Users can register and log in securely with JWT, search across movies and TV shows, filter and sort results, and explore actor profiles complete with IMDb links — all powered by the **TMDb API**.

## ✨ Features

- 🔐 Login / register with JWT-based authentication
- ✅ Form validation using Joi
- 🔍 Search across movies and TV shows
- 🗂️ Filter and sort results
- 🎭 Actor profiles with IMDb links
- 🌐 Real-time data from the TMDb API
- 📱 Fully responsive design across all devices

## ⚙️ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/rawdamohamed2/movieApp
```

**2. Go to the project folder**

```bash
cd movieApp
```

**3. Install dependencies**

```bash
npm install
```

**4. Add your TMDb API key**

Create a `.env` file in the root directory and add your TMDb API key:

```
VITE_TMDB_API_KEY=your_api_key_here
```

**5. Run the development server**

```bash
npm run dev
```

**6. Build for production**

```bash
npm run build
```
